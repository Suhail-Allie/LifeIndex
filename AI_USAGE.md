# AI Usage Declaration – LifeIndex Final POE

During the development of LifeIndex, I used OpenAI ChatGPT as an AI-assisted development and writing tool. I used it to help interpret project requirements, plan implementation steps, explain unfamiliar APIs and libraries, troubleshoot build and runtime errors, and review technical documentation.

AI assistance was used during work on several areas of the application, including Kotlin and Jetpack Compose code, Retrofit and OkHttp integration, the Node.js/Express backend, PostgreSQL and Supabase Storage integration, Room and WorkManager offline synchronisation, Google Sign-In, Firebase notifications, and English, Afrikaans and isiXhosa string resources. ChatGPT also helped analyse compiler output, identify likely causes of errors, draft PowerShell commands and scripts, and prepare the project README and release documentation.

AI-generated suggestions and code were not treated as automatically correct. I reviewed the proposed changes, applied them to the project, resolved issues revealed by the compiler and runtime output, and used Gradle builds, Node.js syntax checks, API health checks, database queries and manual application testing to verify relevant parts of the implementation. For example, I tested Google Sign-In, language switching, push notification delivery, offline tracker synchronisation and the document workflow during development. Some tests were performed on an emulator. The debug application was also successfully installed on a physical Redmi 10 2022 device; the full physical-device functional demonstration is documented separately and should only be described as complete after those checks have been recorded.

I remained responsible for selecting the features, integrating the code into the project, configuring the hosted services, evaluating test results and deciding which changes to retain. AI assistance supported the development process but did not replace implementation, review or testing.
